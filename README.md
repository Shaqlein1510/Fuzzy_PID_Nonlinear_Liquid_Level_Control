# Fuzzy PID Controller for Nonlinear Liquid-Level Control

## About the Project

This is an extracurricular academic project based on the design and simulation of a Fuzzy-PID controller for a nonlinear liquid-level control system using MATLAB and Simulink.

The main aim of this project is to study how fuzzy logic can be used with PID control to improve the response of a nonlinear system. We also compare the performance of a conventional PID controller with a Fuzzy-PID controller using simulation results.

## Objectives

- To understand nonlinear liquid-level control.
- To model the system using MATLAB/Simulink.
- To design a Fuzzy-PID controller.
- To understand the role of fuzzy logic in PID control.
- To compare conventional PID and Fuzzy-PID responses.

## Software Used

- MATLAB
- Simulink
- Fuzzy Logic Designer

## Project Methodology

1. Model the nonlinear liquid-level system in Simulink.
2. Implement a conventional PID controller.
3. Design fuzzy membership functions and control rules.
4. Integrate fuzzy logic with PID control.
5. Simulate the system and compare the controller responses.

## Results

The simulation results are used to compare the conventional PID and Fuzzy-PID controllers based on their liquid-level response and control performance.

The comparison helps us understand the advantages and limitations of using fuzzy logic for nonlinear process control.


## Future Scope

- Test the controller under different operating conditions.
- Tune the controller parameters for improved performance.
- Compare Fuzzy-PID with other intelligent control techniques.
- Explore implementation on a real liquid-level control setup.
